# Развёртывание — коротко

1. **Google Sheets** — создайте новую таблицу → Расширения → Apps Script.
2. Скопируйте `Code.gs`, `index.html`, `stylesheet.html`, `javascript.html`
   в редактор (создайте файлы с такими же именами).
3. Запустите функцию `setupSheets()` один раз (выбрать в выпадающем списке
   вверху редактора → ▶). Разрешите доступ при запросе.
4. В листе **Config**: впишите ваш Telegram-ник без `@` в `ADMIN_USERNAME`.
5. В листе **Players**: на каждого игрока — только одна ячейка,
   `telegram_username` (без `@`), остальное вписывать не нужно. Все
   технические поля (касса, бренд, репутация, статус кредита и т.д.)
   заполнятся сами значениями по умолчанию из `Config` при первом
   обращении — либо когда игрок откроет свой кабинет, либо когда вы
   откроете монитор администратора. Имя и название заведения игрок
   вводит сам при первом входе — короткий экран онбординга перед
   основным кабинетом.
6. **Deploy → New deployment → Web app.**
   Execute as: **Me**. Who has access: **Anyone**.
7. Полученный `.../exec` URL:
   - вставьте в BotFather как Menu Button / Mini App URL вашего бота;
   - тот же URL с `?pub=1` в конце — JSON для будущего публичного сайта;
   - тот же URL с `?u=ваш_ник` — открыть в обычном браузере для теста
     (работает только при `DEV_MODE=TRUE` в Config).

## Лист Config

Третья колонка `description` заполняется автоматически при `setupSheets()` —
у каждого параметра есть расшифровка на русском прямо в таблице, менять
что-либо руками для этого не нужно.

## Проверка перед игрой

- Откройте `?u=<ник_админа>` в браузере — должен открыться пульт ведущего.
- Откройте `?u=<ник_игрока>` (ник, вписанный в Players) — должен появиться
  экран «Добро пожаловать!» с полями имени и заведения. Заполните —
  откроется полный кабинет с формой решения (форма скрыта, пока ведущий
  не нажмёт «Открыть ввод решений»).
- В мониторе администратора у ещё не заполнившего профиль игрока в колонке
  «Подкл.» будет «…», а в «Заведение» — «@ник — ещё не открыл(а) кабинет».
- Нажмите «Открыть ввод решений» → у игрока появится форма → отправьте
  тестовое решение → «Рассчитать месяц» → у игрока должны появиться
  итоги с полосой «обслужено / потеряно».

## Что сознательно упрощено в этой сборке (v0)

- Один сегмент рынка вместо трёх (эконом/масс/премиум) — вернём, когда
  подтвердится, что базовый цикл ощущается правильно.
- Прибыль = денежный поток, за вычетом только тела кредита — без
  амортизации CAPEX.
- Переполнение ёмкости — клиенты просто теряются, без перетока к
  соседям со свободными местами.
- Банкротство — только флаг `status=bankrupt`, без сценариев продажи
  бизнеса/найма — решается вручную с ведущим по ходу игры.
- Формат заведения и реклама действуют в том же месяце, без лага.
- `VERIFY_TELEGRAM_AUTH` выключен — ник берётся из `initDataUnsafe`
  без криптопроверки HMAC. Функция `verifyTelegramInitData_` уже
  в коде, включить — дело следующей итерации, если игра выйдет за
  пределы доверенной комнаты.

Все цифры экономики — в листе **Config**, меняются без переразвёртывания
скрипта (кроме структуры листов).
