# Развёртывание — v0.13

## Что нового в этой версии

- **Табло: понятные объяснения вместо сухих цифр.** Раздел «Техданные» →
  «Маркетинговые каналы» теперь объясняет на пальцах, что такое «вес» и
  «альфа» (с примером и таблицей — во сколько раз растёт эффект при
  бюджете 2×/5×/10× от опорного), плюс отдельные объяснения с примерами
  для **Качества** (линейный курс вложений, без убывающей отдачи) и
  **Партнёрской программы** (фиксированный бонус к выручке, переплата
  сверх минимума бесполезна).
- **Таймер на табло** перенесён внутрь шапки (рядом с «Месяц X из Y») и
  сильно уменьшен. Раньше он был отдельным блоком в потоке документа —
  при появлении/исчезновении вся разметка ниже (вкладки, график,
  техданные) сдвигалась, а фиксированная высота области с графиком
  (`calc(100% - 160px)`) не поспевала за этим сдвигом — из-за чего внизу
  списка каналов не хватало прокрутки. Переложил раскладку страницы на
  флексы: область с графиком/техданными теперь занимает ровно оставшееся
  место, сколько бы строк ни занимали вкладки и виден таймер или нет.
- `CAPACITY_BASE` по умолчанию — 3000 (было 1000 в прошлой версии).

## Обновление уже развёрнутого проекта

1. Замените `Code.gs` — добавлен блок `quality` в `techInfo`.
2. **Deploy → Manage deployments → ✏️ → Version: New version → Deploy.**
3. Замените `tablo.html`, `tablo.css`, `tablo.js`.
4. `index.html`, `Style.css`, `App.js` — без изменений в этой версии.
5. В листе Config при необходимости поправьте `CAPACITY_BASE` вручную —
   существующие значения `setupSheets()` не перезаписывает.

## Архитектура (без изменений)

- **`Code.gs`** — бэкенд на Apps Script, JSON API, всё через GET.
- **`index.html` + `Style.css` + `App.js`** — кабинет игрока/администратора.
- **`tablo.html` + `tablo.css` + `tablo.js`** — табло для проектора/ТВ.
- **`EXEC_URL` меняется в ДВУХ местах**: `App.js` и `tablo.js`.

## 1. Google Sheets + Apps Script (бэкенд)

1. Создайте таблицу → Расширения → Apps Script (или откройте существующий
   проект).
2. Скопируйте содержимое `Code.gs` в редактор, полностью заменив старое.
3. Запустите `setupSheets()` (▶ в редакторе — результат смотрите в
   логах, не во всплывающем окне).
4. В листе **Config**: `ADMIN_USERNAME` — ваш ник без `@`. Проверьте
   `CAPACITY_BASE` (3000), `START_CAPITAL` (100000), `MARKET_SIZE_PER_PLAYER`
   (10000), `MARKET_SCALES_WITH_PLAYERS` (FALSE) — если запускаете не с
   нуля, поправьте вручную.
5. В листе **Players**: на игрока — только `telegram_username` (без `@`).
6. **Deploy → New deployment → Web app.** Execute as: **Me**.
   Who has access: **Anyone**.

## 2. GitHub Pages (фронтенд)

1. Публичный репозиторий, в корень: `index.html` (строго строчными!),
   `Style.css`, `App.js`, `tablo.html`, `tablo.css`, `tablo.js`.
2. `EXEC_URL` в начале **и `App.js`, и `tablo.js`**.
3. Settings → Pages → Source: `main` / `/ (root)`.
4. Кабинет: `https://<логин>.github.io/<репо>/` — в BotFather.
   Табло: `.../tablo.html` — на проектор/ТВ отдельной вкладкой.

## Проверка перед игрой

- Табло → «Техданные»: прокрутите до конца — все карточки маркетинговых
  каналов, качества и партнёрки должны быть видны и читаемы, включая
  таблицу масштабирования бюджета.
- Откройте месяц с таймером — он должен появиться небольшим прямоугольником
  в шапке рядом с номером месяца, не сдвигая вкладки и график.
- Остальные проверки — как в прошлых версиях.

## Что сознательно упрощено в этой сборке (v0)

- Один сегмент рынка вместо трёх (эконом/масс/премиум).
- Переполнение ёмкости — клиенты просто теряются, без перетока к соседям.
- Формат заведения, реклама (кроме Google Карт) и вложения в качество
  действуют в том же месяце, без лага.
- `VERIFY_TELEGRAM_AUTH` выключен в `Config` — ник берётся из
  `initDataUnsafe` без криптопроверки HMAC.
- Численные коэффициенты 6 маркетинговых каналов, зарплата в найме и
  порог переоткрытия — v0-интерпретация, требуют калибровки по живым
  прогонам.

Все цифры экономики — в листе **Config**, меняются без переразвёртывания
Apps Script (кроме структуры листов) и без прикосновения к GitHub Pages.
